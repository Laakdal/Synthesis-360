# Public sources: ASM research

All sources were accessed on **2026-10-17**. The **Access** column says how much of each source was actually read:

- **full**: the page or document was opened and read (WebFetch, or curl plus tag stripping).
- **snippet**: the page refused automated access (HTTP 403 or a login wall), so only the search-engine excerpt was seen. Do not rely on a snippet source alone for a load-bearing claim.
- **catalog**: the bibliographic details were confirmed from catalogue or publisher records seen in search results. The work itself was not read.

Fusion API base URL: `https://help.autodesk.com/cloudhelp/ENU/Fusion-360-API/files/`, written below as **API/**. Unprefixed page names such as `TemporaryBRepManager.htm` and `BRepBody.htm` return 404. Pages for objects in the `adsk.fusion` namespace use the `fusion_` prefix, and pages for `adsk.core` use `core_`.
